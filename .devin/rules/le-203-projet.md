# LE 203 — Project Rules

- Ne jamais inventer de données immobilières, financières, juridiques ou fiscales.
- Ne jamais effectuer de commit, push, reset, revert ou autre opération Git sans demande explicite.
- Ne jamais supprimer un asset ou un fichier sans autorisation explicite.
- Préserver les fonctionnalités existantes non concernées par la tâche demandée.
- Privilégier la modification minimale nécessaire et éviter les refactorisations sans rapport avec la demande.
- Réutiliser les composants et fonctionnalités existants lorsqu'ils répondent au besoin.
- Ne jamais exposer, inventer ou modifier arbitrairement des secrets, tokens, API keys ou variables d'environnement sensibles.
- Après une modification significative du code, vérifier TypeScript, lint et build lorsque cela est pertinent.
